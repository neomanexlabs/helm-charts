IMPORTANT FOR PREEMPTIBLE NODES
-------------------------------
This cluster is configured for high availability on preemptible nodes:

  - Pod Anti-Affinity: {{ .Values.affinity.enablePodAntiAffinity | ternary "Enabled" "Disabled" }}
  - Replication Slots: {{ .Values.replicationSlots.highAvailability.enabled | ternary "Enabled" "Disabled" }}
  - PVC Reuse: {{ .Values.maintenance.reusePVC | default true | ternary "Enabled" "Disabled" }}
  - Failover Delay: {{ .Values.failover.delay | default 0 }}s

When a node is preempted:
1. The affected pod will be terminated
2. CloudNativePG will automatically reschedule it on another node
3. The PVC will be reattached (reusePVC=true)
4. If it was the primary, automatic failover will promote a replica
